Для каждого предложения дай перевод предложения целиком и сделай морфологический разбор с переводом начальных форм.

## Дробность разбора (главное правило)

**По умолчанию: одно слово исходного предложения — один элемент `breakdown`.** Элементы идут в том же порядке, что и слова в предложении, и вместе покрывают предложение целиком, без пропусков.

Объединять несколько слов в один элемент можно **только** в этих четырёх случаях:

1. **Аналитическая глагольная форма**: деепричастие на `-ып/-іп/-п` со вспомогательным глаголом (`отыр`, `жатыр`, `тұр`, `жүр`, `қал`, `кет`, `бер`, `көр` и т. п.) — например `оқып отыр`, `келіп отыр`, `айтып өт`.
2. **Изафет, образующий одно понятие**: `білім бөлімі` («отдел образования»), `оқу жылы` («учебный год») — то есть устойчивое название, а не любое сочетание с притяжательным аффиксом.
3. **Имя собственное целиком**: имя + фамилия/патроним, например `Жомарт Касенұлы`.
4. **Устойчивое выражение или идиома**, которая не разбирается по частям.

Во всех остальных случаях слова **разделяются**. В частности, разделяй:

- прилагательное и существительное: `жаңа` + `оқулық`, а не `жаңа оқулық`;
- существительное и послелог: `көрсеткіші` + `бойынша`, а не `көрсеткіші бойынша`;
- любые цепочки из трёх и более знаменательных слов — их нельзя склеивать в один элемент.

Ориентир для самопроверки: **число элементов `breakdown` должно быть близко к числу слов в предложении** и почти никогда не меньше двух третей от него. Если элементов получилось заметно меньше — ты склеил лишнее, разбери подробнее.

## Комментарии

Поле `comment` описывает грамматическую форму: назови аффиксы и их роль (падеж, число, лицо, притяжательность, время, залог, наклонение). Пиши по-русски, простыми словами, без лингвистического жаргона сверх необходимого.

- Если слово содержит хотя бы один аффикс — комментарий **обязателен**, и в нём должен быть назван сам аффикс.
- Если слово стоит в словарной форме без аффиксов — комментарий можно оставить пустым.

## Перевод предложения

В `translations` давай **два варианта**: естественный литературный перевод и более буквальный, показывающий структуру оригинала. Если предложение состоит из одного слова или это формула вежливости, достаточно одного варианта.

## Одинаковая подробность

Предложений во входных данных может быть много. **Подробность разбора не зависит от их количества**: последнее предложение разбирается так же тщательно, как первое, а длинное — так же тщательно, как короткое. Не сокращай разбор, не укрупняй элементы и не урезай комментарии ради краткости ответа.

## Пример нужной дробности

Для предложения `Жаңа оқулықты оқып отырмын.` (4 слова) правильный разбор содержит 3 элемента: `жаңа` и `оқулықты` разделены, объединена только аналитическая глагольная форма `оқып отырмын`.

```json
{
    "sentence_num": 1,
    "sentence": "Жаңа оқулықты оқып отырмын.",
    "translations": ["Я читаю новый учебник.", "Сейчас я читаю новый учебник."],
    "breakdown": [
        {
            "word": "Жаңа",
            "pos": "прилагательное",
            "base": "жаңа",
            "base_translation": "новый",
            "word_translation": "новый",
            "comment": ""
        },
        {
            "word": "оқулықты",
            "pos": "существительное",
            "base": "оқулық",
            "base_translation": "учебник",
            "word_translation": "учебник (кого/что)",
            "comment": "Винительный падеж: аффикс -ты указывает на прямой объект действия."
        },
        {
            "word": "оқып отырмын",
            "pos": "глагольная конструкция",
            "base": "оқу",
            "base_translation": "читать",
            "word_translation": "читаю (прямо сейчас)",
            "comment": "Аналитическая форма: оқы- «читать» + деепричастие -ып, вспомогательный глагол отыр передаёт длящееся действие, -мын — окончание 1-го лица единственного числа."
        }
    ]
}
```

## Формат ответа

Ответ должен быть в JSON. Поле `sentence_num` — номер предложения из входных данных. Разбери **все** предложения.

```json
{
    "sentences": [
        {
            "sentence_num": 1,
            "sentence": "The original sentence.",
            "translations": ["Variant of Russian translation of the sentence.", ... ],
            "breakdown": [
                {
                    "word": "The word or phrase from the sentence.",
                    "pos": "Part of speech of the word or phrase.",
                    "base": "Base or dictionary form of the word or phrase.",
                    "base_translation": "Russian translation of the base form.",
                    "word_translation": "Russian translation of the word or phrase",
                    "comment": "optional explanatory comment for the grammar form, including suffixes and their roles."
                },
                { ... }
            ]
        }
    ]
}
```
